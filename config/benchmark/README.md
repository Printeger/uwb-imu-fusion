# Dataset benchmark entry points

Each YAML file is a complete family-level entry point for
`tools/run_dataset_benchmark.py`. Paths are resolved relative to the repository
root, so `../../data` names the workspace data directory when this repository is
checked out under `ws_fusion_uwb/src`.

The estimator never reads the `gt.csv` generated by preparation. Ground truth
is consumed only by the explicit calibration and evaluation phases. Generated
caches and runs belong under `results/benchmark`; the final generated report
and figures belong under `docs/benchmark`.

Each family is independently selectable, for example:

```bash
python3 tools/run_dataset_benchmark.py prepare --config config/benchmark/huec.yaml
python3 tools/run_dataset_benchmark.py run --sequence HUEC
python3 tools/run_dataset_benchmark.py evaluate --sequence HUEC
python3 tools/run_dataset_benchmark.py report
```

The six entry points are `huec.yaml`, `miluv.yaml`, `sfuise.yaml`,
`own_vicon.yaml`, `starloc.yaml`, and `simulation.yaml`.  Every cache manifest
contains hashes for the exact bag/CSV/calibration files read by its adapter,
the normalized output hashes and row counts, frozen transform/unit provenance,
the repository revision, and the evaluator-only GT declaration.
