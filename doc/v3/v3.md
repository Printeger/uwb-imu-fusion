> 如何保持 4–8 Hz state，但使用 16 Hz 全部 UWB。

否则现在一上来引入 interpolation / B-spline，你的代码一定会再次复杂化。

## 我建议你给 Codex 的总原则

每一个 Prompt 最前面都可以再加这一段：

```text
PROJECT RULE:

Do not optimize for adding features.

Optimize for reducing ambiguity in system semantics.

When there are two possible implementations, prefer the smaller one that preserves explicit contracts.

Do not opportunistically fix unrelated issues.

Do not create new abstractions unless they directly enforce one of the stated contracts.

Do not modify scientific algorithms outside the stated task boundary.

If completing the requested change requires crossing a hard boundary, STOP and report the blocker instead of silently expanding scope.
```

这一段很重要。

它会显著降低 Codex 又出现：

> “顺手增加了一个新的 detector / 新配置 / 新 experiment / 新 fallback”

这种情况。

**执行时就从 Prompt 1 开始，不要一次把 6 个 Prompt 全丢给 Codex。每个 Gate 完成后先检查它的 report 和 diff，再进入下一步。**
